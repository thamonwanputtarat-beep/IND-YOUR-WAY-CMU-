รายชื่ออาคารและสถานที่สำคัญ

8 สถานที่
ข้อมูลรถไฟฟ้า มช. (รถม่วง Sook Jai EV Bus)

สาย 1: ศาลาธรรม - หอพักนักศึกษา - อ่างแก้ว

ผ่าน: ศาลาธรรม, สำนักหอสมุด, คณะมนุษยศาสตร์, คณะวิศวฯ, อ่างแก้ว

สาย 2: ประตูหน้า มช. - คณะวิทยาศาสตร์ - สปอร์ตคอมเพล็กซ์

ผ่าน: ประตูหน้า มช., อาคารเรียนรวม CB1, คณะวิทยาศาสตร์, CAMT

สาย 3: หอพักชาย/หญิง - ตลาดร่มฝ้าย - ประตูไผ่ล้อม

ผ่าน: ตลาดอมรพรรณ, ศูนย์อาหาร, คณะบริหารธุรกิจ, คณะสื่อสารมวลชน

คำแนะนำสำหรับนักศึกษาใหม่ & ผู้มาเยือน
1

ค้นหาได้ทันที: พิมพ์เลขห้องเรียน เช่น HB7801 หรือชื่ออาคาร HB7 ในช่องค้นหาด้านบน

2

ดูผังห้องเรียน: กดปุ่ม "ดูแผนผังชั้นห้อง" เพื่อดูตำแหน่งห้องเรียน ทางเข้า บันได และลิฟต์ในแต่ละชั้น

3

นำทางแม่นยำ: เลือกระบบนำทางเพื่อคำนวณระยะทาง เวลา และเส้นทางรถม่วง หรือเปิดด้วย Google Maps

ตั้งค่า Google Maps API / Demo Mode

ระบบปัจจุบันทำงานในโหมด OpenStreetMap Interactive Demo Mode พร้อมพิกัดจริงของมหาวิทยาลัยเชียงใหม่โดยไม่ต้องใช้ API Key

* หากไม่มี API Key ระบบจะใช้บริการแผนที่OpenStreetMap แบบตอบสนองทันที
