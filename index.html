ข้อมูลรถม่วง มช. (ตัวอย่าง)

ข้อมูลสายรถในหน้านี้เป็นข้อมูลตัวอย่าง ควรตรวจสอบตารางเดินรถจริงก่อนใช้งาน

วิธีใช้งาน
  1. พิมพ์เลขห้อง เช่น HB7801 หรือชื่ออาคาร
  2. เลือกผลลัพธ์เพื่อดูตำแหน่งและผังชั้นตัวอย่าง
  3. กดเปิด Google Maps เพื่อดูเส้นทางภายนอก
การตั้งค่าแผนที่

แผนที่ใช้ OpenStreetMap ไม่ต้องใช้ Google Maps API Key

ข้อมูลห้อง ผังชั้น และเส้นทางในต้นแบบนี้เป็นข้อมูลตัวอย่างบางส่วน
